## [0.1.0] — 2026-11-19

Первая версия. Сканер, записи, анализ и ИИ-помощник работают; проверка на реальной машине и адаптере — следующий шаг, дальше версия будет улучшаться по результатам тестов на железе.

### Диагностика
- Подключение к ELM327 по Bluetooth, Wi-Fi и USB OTG; демо-адаптер для работы без машины.
- Протоколы CAN и K-Line (ISO 9141 / KWP2000), многокадровые ответы.
- Живые данные стандартных PID (сервис 01) на панели.
- Чтение и сброс кодов ошибок, история кодов по машине. Описания: встроенная база, плюс по запросу OBDex (причины и симптомы) и заводские коды Wal33D — только для марки активной машины.

### Записи и статистика
- Запись сессий в фоне, графики, экспорт в CSV.
- Поездки из собственных записей: пробег по скорости, расход по PID топлива или оценка по MAF, время в движении и на месте.
- Вкладка «Статистика»: поездки, км, литры, средний расход, траты на топливо за неделю, месяц, год и всё время.

### Анализ и обслуживание
- Детерминированные правила: топливные коррекции и разница банков, перегрев, недо- и перезаряд, MAF на холостых (по объёму двигателя), прогрев, связанные и повторяющиеся коды, пробег с горящим Check Engine.
- Фоновый анализ после записи и импорта; уведомление только о новых находках уровня «Внимание» и выше.
- ТО: шаблон работ для бензиновой машины, интервалы по пробегу и месяцам, оценка текущего пробега, ежедневное напоминание.

### ИИ-помощник
- Провайдеры из пресетов Koog (OpenRouter, OpenAI, Anthropic, Google, DeepSeek, Mistral, Ollama) и свой OpenAI-совместимый сервер.
- Модель читает данные машины через read-only инструменты: профиль без VIN, поездки, записи, статистика датчиков, находки, история кодов, ТО.
- Согласие перед первой отправкой данных в облако, сохранение истории чата, «Новый диалог».
- Сборка «Локально»: модели на телефоне (LiteRT через Koog). Каталог Koog + Google AI Edge Gallery + поиск по Hugging Face, оценка «потянет ли» до скачивания, бенчмарк CPU / GPU / NPU после, докачка больших файлов.

### Данные и перенос
- Импорт полного бэкапа Car Scanner (`.cbz`): записи, поездки, события кодов, профиль машины, единицы и цена топлива. Повторный импорт добавляет только новое и не перетирает ручные правки. Импорт идёт в фоне с прогрессом в уведомлении.
- Резервная копия ECULense (`.eculense`) и восстановление; ключи API в копию не попадают.
- Справочники по запросу: характеристики машин (gor3a), коды ошибок (OBDex, Wal33D), сигналсеты OBDb (просмотр).
- Профиль машины с заполнением из справочника.

### Сборки
- Две сборки одного приложения: «Облако» (≈ 10 МБ) и «Локально» (≈ 35 МБ, плюс модели на телефоне).

### Известные ограничения
- Не проверено на реальном адаптере ELM327 и на машине; USB OTG не проверен.
- Расширенные (заводские) PID не опрашиваются: нужны адресация блоков и сервисы 21/22.
- Gemma на телефоне не вызывает инструменты сама — локальная модель получает готовую сводку по машине.
- Интерфейс только на русском. Другие языки будут, но не в первом приоритете.
